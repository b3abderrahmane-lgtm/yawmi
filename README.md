# يومي

النوبة · الصلاة · النوم · التمرين — تطبيق ويب يُثبَّت على الهاتف، مع تنبيهات تيليغرام تصل والتطبيق مغلق.

## كيف تعمل التنبيهات

1. التطبيق يحسب جدول 14 يوماً قادمة (نفس الجدول الذي تراه على الشاشة) ويرفعه إلى متغيّر المستودع `YAWMI_EVENTS`.
   يُعاد الرفع تلقائياً بعد كل تغيير (يوم راحة، صيام، مهمة جديدة، إنجاز مهمة…) وكلما فتحت التطبيق.
2. `notify.py` يعمل على GitHub Actions، ينتظر موعد كل مهمة، ويرسل تنبيهاً قبلها بـ 5 دقائق،
   وجدول اليوم كاملاً عند منتصف الليل بلا صوت.
3. المهمة المعلَّمة منجزة لا يصل تنبيهها.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.json` · `sw.js` · `icon-*.png` | التثبيت على الهاتف والعمل دون إنترنت |
| `notify.py` | مرسل التنبيهات |
| `.github/workflows/notify.yml` | تشغيله كل ساعة، وفوراً بعد كل مزامنة |

## الأسرار والمتغيّرات

| الاسم | النوع | القيمة |
|---|---|---|
| `TG_TOKEN` | Secret | توكن البوت |
| `TG_CHAT` | Secret | رقم محادثتك |
| `YAWMI_EVENTS` | Variable | يكتبه التطبيق — لا تعدّله يدوياً |

لتغيير مدة التنبيه المسبق: `LEAD_MIN` في `notify.yml`.
